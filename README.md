# Калькулятор закосов венткоробов

React + Vite + Tailwind CSS. Настроен для публикации на GitHub Pages в репозитории `ventkorob-calculator`.

## Публикация
1. Создайте на GitHub публичный репозиторий с именем `ventkorob-calculator`.
2. Загрузите в него содержимое этой папки, включая скрытую папку `.github`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: GitHub Actions.
5. Откройте вкладку Actions и дождитесь успешного выполнения `Deploy Vite app to GitHub Pages`.
6. Сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/ventkorob-calculator/`.

Если вы назовёте репозиторий иначе, измените `base` в `vite.config.ts` на `'/ИМЯ-РЕПОЗИТОРИЯ/'` до загрузки.
